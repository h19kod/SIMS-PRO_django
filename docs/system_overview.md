# 📚 دليل نظام إدارة معلومات الطلاب (SIMS PRO)

## 🌟 مقدمة عن المشروع
نظام **SIMS PRO** هو منصة تعليمية متكاملة مبنية باستخدام إطار عمل **Django**. يهدف النظام إلى تسهيل عملية إدارة بيانات الطلاب، الأقسام الدراسية، ورصد الدرجات الأكاديمية بشكل ديناميكي مع دعم كامل للوضع الليلي (Dark Mode).

---

## 🛠 التقنيات المستخدمة (Tech Stack)
1. **Django 6.x**: المحرك الأساسي (Backend) لإدارة قواعد البيانات والروابط.
2. **Bootstrap 5**: لتصميم واجهة المستخدم وجعلها متجاوبة مع الهواتف والحواسيب.
3. **SQLite**: قاعدة بيانات مدمجة وسريعة لتخزين معلومات الطلاب والدرجات.
4. **SweetAlert2 & Lucide Icons**: لإضافة لمسات جمالية وأيقونات تفاعلية.

---

## 📂 هيكلية الملفات (Project Structure)
- **`students/`**: تطبيق خاص بإدارة الملفات الشخصية للطلاب (الاسم، القسم، المرحلة).
- **`management/`**: التطبيق المسؤول عن "العمليات" مثل إضافة المواد، رصد الدرجات، وعمليات الحذف.
- **`templates/`**: يحتوي على ملفات HTML التي تظهر للمستخدم.
- **`static/`**: يحتوي على ملفات CSS و JavaScript الخاصة بالتصميم.

---

## 🚀 الوظائف البرمجية الأساسية
### 1. إدارة الطلاب
- إضافة طالب جديد مع تخصيص قسم ومرحلة دراسية.
- حذف طالب (مع ميزة التأكيد لمنع الحذف بالخطأ).
- بحث فوري (Live Search) عن الطلاب بالاسم أو الرقم الجامعي.

### 2. الأداء الأكاديمي
- رصد الدرجات لكل مادة على حدة.
- حساب تلقائي للمعدل التراكمي.
- عرض "تقدير" الطالب تلقائياً (امتياز، جيد جداً، إلخ) مع تغيير لون الحالة برمجياً.

### 3. واجهة المستخدم الذكية
- دعم الوضع الليلي (Dark Mode) لحماية عين المستخدم.
- تصميم متجاوب (Responsive Design) يعمل على كل الشاشات.

---

## 🔧 كيفية التشغيل (للأغراض التطويرية)
1. تثبيت المتطلبات: `pip install django`
2. تشغيل السيرفر: `python manage.py runserver`
3. الدخول للوحة التحكم: `http://127.0.0.1:8000/`
