# 📚 توثيق نظام إدارة الطلاب (SIMS PRO)

## 🛠 التقنيات المستخدمة:
- **Framework:** Django 5.x
- **Frontend:** Bootstrap 5 (مع دعم Dark Mode)
- **Database:** SQLite (للبيانات المحلية)

## 📂 هيكلية المشروع:
- `students/`: إدارة بيانات الطلاب الأساسية.
- `management/`: إدارة المواد، الدرجات، وعمليات الحذف.
- `templates/`: ملفات الواجهة الأمامية الديناميكية.

## 🚀 الوظائف الأساسية:
1. **إضافة طلاب**: عبر نماذج Django مأمنة.
2. **رصد الدرجات**: نظام حساب تلقائي للمعدلات والتقديرات.
3. **الحذف الآمن**: ميزة الحذف مع تأكيد JavaScript لمنع الأخطاء.
